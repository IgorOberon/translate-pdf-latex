# Дополнительные скиллы и состав переносимого пакета

Скиллы — инструкции для конкретных задач, а не обязательные компоненты движка.
Исторический каталог содержал 26 экспертных скиллов. 15 ноября 2026 добавлен
`translation-pipeline-diagnostics`: в каталоге теперь 27 дополнительных
скиллов, помимо основного `translate-pdf-latex`.

В основной ZIP beta.5 включены **пять** дополнительных папок:

- [local-mt-batch](../companion-skills/local-mt-batch/SKILL.md): фрагментный кэш и возобновление;
- [local-llm-lmstudio](../companion-skills/local-llm-lmstudio/SKILL.md): контекст, ошибки API и измерение скорости;
- [latex-build-doctor](../companion-skills/latex-build-doctor/SKILL.md): сохранная сборка и техническая приёмка;
- [translation-glossary-builder](../companion-skills/translation-glossary-builder/SKILL.md): полный словарь и выборка для запроса;
- [translation-pipeline-diagnostics](../companion-skills/translation-pipeline-diagnostics/SKILL.md): чтение состояния и диагностика повторной работы.

Первые четыре обновлены по проверенному коду конвейера; последний создан заново.
Их инструкции обращаются к одному движку в `scripts/`. Исторические копии
переводчика из внешней коллекции в пакет не включены. Остальные 22 скилла
остаются отдельными экспертными инструментами; их наличие в этом ZIP не заявлено.
Все 27 доступны в [репозитории](https://github.com/IgorOberon/translate-pdf-latex/tree/main/companion-skills)
и отдельном `companion-skills.zip` в [beta.5](https://github.com/IgorOberon/translate-pdf-latex/releases/tag/v0.1.0-beta.5).
Пять папок пересекаются с основным пакетом: устанавливать дубликаты не нужно.

## Как выбирать и устанавливать

Для обычного локального перевода достаточно `translate-pdf-latex` и его внешних
зависимостей по [установке](../УСТАНОВКА.md). Дополнительные скиллы выбираются
под конкретную задачу, а не загружаются все в контекст агента перед каждой книгой.

Если у вас уже есть коллекция, переносите выбранную папку **целиком**, с её
`scripts/`, `references/` и `assets/`, в каталог скиллов своего клиента. Если клиент
не поддерживает автоматическое обнаружение, можно явно поручить прочитать её
`SKILL.md`. Каждая экспертная задача может требовать собственных зависимостей.

Для включённых пяти скиллов можно оставить папки внутри пакета и прочитать
нужный `SKILL.md` по ссылкам выше. Для автоматического обнаружения скопируйте
только выбранную папку из `companion-skills/` в каталог скиллов клиента.
Существующую установленную версию сначала сохраните. Основной конвейер и его
Python-окружение должны быть доступны отдельно; скилл находит активный проект
по контексту пользователя, а не по зашитому пути конкретного компьютера.

Скилл не является моделью и сам по себе не требует платной подписки. Но глубокая
вычитка, vision-проверка и многoагентный аудит расходуют ресурсы выбранной модели;
они не включаются конвейером автоматически. Старые копии скриптов из коллекции
не должны заменять актуальные проверенные скрипты основного конвейера.
